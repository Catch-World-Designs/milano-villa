# Approved prototype visual baseline

These files preserve the final Arena prototype before production refactoring.
They are design references and must not be regenerated unless the approved
design itself changes.

- Desktop viewport: 1440 × 900
- Mobile viewport: 390 × 844
- Capture format: full-page JPEG, quality 88
- Motion setting: `prefers-reduced-motion: reduce`
- Route mode at capture time: prototype hash routing

Run `npm run baseline:capture` against `http://127.0.0.1:4173` only when an
explicitly approved design change requires a new baseline.
